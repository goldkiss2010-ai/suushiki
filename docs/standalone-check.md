# 単体確認の実測記録

確認日：2026-10-10 UTC。これは実行計画の「起動環境 → Stone 単体 → MathJax 単体」の確認です。統合した数式組版の合格記録ではありません。

## 環境

- Linux、Node.js `24.19.0`、npm `11.9.0`。
- Chromium headless `153.0.8010.0`、Playwright を用いた操作と画面の目視確認。
- 和文フォールバックに Noto Sans JP、欧文に DejaVu 系のシステムフォント。これらは検証環境のフォントで、リポジトリには同梱していない。
- Stone npm `0.2.0`、MathJax npm `4.1.3`、MathJax New Computer Modern `4.1.3`。
- `npm ci`、`npm run dev`、HTTP による依存ファイル配信を確認した。

Windows の PowerShell 手順は用意したが、Windows 上の実行は未確認。測定値は OS とフォントによって変わる。

## 確認結果

| 操作・観察 | 結果 |
| --- | --- |
| 初期表示、幅 480 px / 文字サイズ 20 px | 和文が４行、４式が表示され、数値を取得できた |
| 幅を 160 px に変更 | 和文が11行になり、切り詰めはなし。４式の幅は変わらなかった |
| 文字サイズを 20 → 24 px に変更 | ４式の幅と高さが増え、再計測できた |
| ゴシック／明朝の切り替え | 再計測が完了した。特定のフォントへの解決や数値差は OS に依存する |
| 文字枠表示の切り替え | 表示を変更できた |
| JSON 保存 | 設定、依存版、原文、Stone の文字座標、４式の原式と寸法を保存できた |
| ブラウザーの例外・警告・失敗したリクエスト | 最終確認ではいずれもなし |
| 外部ホストへのリクエスト | 外部への通信を遮断した状態で表示と追加数式フォントの読み込みが成功した |

幅480 px、文字サイズ20 pxにおける SVG 矩形の例：

| TeX | 幅 | 高さ | ベースライン上側 | ベースライン下側 | SVG 数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `f(x)=x^2` | 105.016 | 26.766 | 20.641 | 6.125 | 1 |
| `\frac{1}{1+x^2}` | 50.891 | 32.188 | 21.406 | 10.781 | 1 |
| `\dfrac{\sum_{k=1}^{n} k^2}{1+\dfrac{1}{x}}` | 98.359 | 88.734 | 39.266 | 49.469 | 1 |
| `x\in\mathbb{R}` | 62.266 | 18.000 | 16.953 | 1.047 | 1 |

単位は CSS px、小数第３位まで丸めている。高さと上側・下側の和の差は丸め誤差の範囲内だった。これは表示された SVG の外枠の測定で、字形のインク領域を測ったものではない。

初期設定の Stone の行送りは32 px。背の高い式は約89 pxあった。今後、同じ段落に接続する際に、数式の上下寸法を行の占有領域へ反映する必要がある。今回の画面では別々の領域に置いており、重なりの解消を検証したわけではない。
