# 数式内部と日本語本文の境界：余白・約物・LuaLaTeX比較

**検索語**：数式境界／和欧文間の空き／数式前後のアキ／数式内部／MathJax SVG／TeX xkanjiskip／LuaLaTeX／jlreq／四分アキ／quarter／contextual／elastic／禁則とアキ。

対象：K01/T01、K02/T02a・T02b・T02c・T02d。

## 1. 「数式内部」と「本文との境界」を分ける（T01）

TeXやMathJaxの内部では、演算記号の意味に応じた間隔、上付き・下付き、分数、根号、伸びる括弧などを処理します。日本語の本文側には文字クラス、約物詰め、禁則、和欧文の間隔という別の処理があります。

問題設定は、**同じ文字・箱の間隔をMathJaxと段落組版の両方が重ねて操作しないこと**です。現行SUUSHIKIでは数式をMathJaxの出力単位として保持し、段落側にその幅・ベースラインからの上昇寸法・下降寸法を渡して組版します。

T01（数式内部の分数と可変括弧）は、原文の保持、数式ボックスの一体性、元SVGと座標の整合を機械的に確認した条件です。**内部のすべての数式組版規則をSUUSHIKIが実装・検証したという意味ではありません。** 数式内部の品質評価はMathJax側の責任と区別します。

## 2. 原文の空白と自動アキは異なる（T02）

T02a・T02bの対照原稿は以下です。

空白なし：

    関数\(f(x)=x^2\)を考える。

明示の半角空白あり：

    関数 \(f(x)=x^2\) を考える。

見た目の「アキ」は、原文に含まれる空白、数式SVGの計測寸法、和欧文・数式境界の組版上のアキ、約物自身の占有幅によって生じます。測定・規則選択の時点で、これらを混同してはいけません。

SUUSHIKIの既存の試験設定は以下の通りです。

| 数式の外側の指定 | 実装・解釈 |
| --- | --- |
| none | 元の文章に明示された空白を保持し、自動生成アキは付けない |
| quarter | 左右とも隣接文字がある場合に本文サイズの1/4を生成する単純な比較条件。約物も対象 |
| contextual | 文字・数字が隣接する側だけ1/4を候補とし、約物・記号・元の空白の隣は付加しない |
| elastic | contextualに対応する自然幅のほか、伸び・縮みの予算を計測記録へ残す。**実配置では自然幅しか使わない** |

本文20 CSS pxなら1/4 em相当の試験値は片側5 CSS pxです。しかし、TeXの1/4 zwとの一致を意味しません。また、出版物に共通する唯一の正しいアキ量として採用したものではありません。

折り返し後に数式が行頭・行末になった場合、行端側の不要な付加アキを再評価する処理を持っています。元ソースのスペースはそのまま保持し、後から原文を勝手に書き換えることはしません。

実装・未実装の範囲は[従来のT02実験仕様](../math-boundary-spacing.md)を参照。

## 3. 実際のLuaLaTeX＋jlreqとの測定（T02d）

比較基準として、LuaHBTeX 1.18.0／TeX Live 2025/dev／jlreq 2024-10-04／本文10ptの実測ログが保存されています。

この条件でのxkanjiskipは「自然幅2.5pt・伸長2.5pt・縮小1.25pt」。和文全角幅zw=10ptとした無次元比では、それぞれ0.25zw、0.25zw、0.125zwです。

空白なしのT02aを1個のhboxとして測定した値：

| 内訳 | LuaLaTeXの測定結果 |
| --- | ---: |
| 文章全体 | **113.00021 pt** |
| 左「関数」 | 20.00000 pt |
| 式「f(x)=x²」 | 43.00021 pt |
| 右「を考える。」 | 45.00000 pt |
| 3項目の和との差 | **5.00000 pt** |

差の5ptは、左右合計のxkanjiskip自然幅（2.5ptずつ）と一致します。これは、この**固定した原稿・TeX環境**における測定です。

同じ文を2回続けた原稿では、12zw（名目の幅比）で2行、24zwで1行と測定されました。これはTeXのフォントや最適化が変わっても常に同じ行数になるという保証ではありません。

**単位に注意**：LuaLaTeXのpt／zwとブラウザーのCSS px／emは同一ではなく、jlreq側のJFM・和文フォントとMathJaxのフォントも異なります。単純な画素・行数の一致を合否基準にはできません。

出典： [再実行できるTeX測定説明](../latex-benchmark.md)、[実際のTeXソース](../../benchmarks/latex/reference.tex)、[測定ログ](../../benchmarks/latex/reference-log.txt)。

## 4. 確認された範囲と残りの不確実性

**実際に確認**
- T02a/T02bを区別し、明示空白と自動アキを重複して加えない試験方針を実装した。
- T02cでは、約物・句読点が隣接する場合のquarterとcontextualの違いを比較できる。
- 計測用のMathJax SVG幅と原稿TeX、数式出現IDの対応を維持している。
- LuaLaTeXの具体的な1条件を実測値で照合できる。

**まだ確認していない**
- この試験アキ方針が、日本語数式組版の標準・出版慣行における最善の値かどうか。
- 本文の両端揃えの伸縮余地を実際に配置へ配分した結果。elasticのappliedAdjustmentは現実には0のまま。
- 光学的な約物とSVG字形のインク領域の適切な調和。
- 日英混植・数式の複雑な境界における包括的な最適改行。

**判断**：T01/T02は「新しい組版法が既存より優秀である」と示した実験ではなく、原文・本文・数式・付加アキを別々の測定対象とする**接続契約**の確認です。既存のTeX/CSS/MathJaxを置き換えるための新機能開発を、この調査記録から自動的に導きません。

各資料への入口は[測定・出典台帳](05-method-and-evidence.md)へ。
