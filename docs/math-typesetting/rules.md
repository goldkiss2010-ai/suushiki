# 数式組版ルール一覧

調査日：2026-10-10。出典番号は [sources.md](sources.md)、確認例 C01–C32 は [math-typesetting-cases.md](../../examples/math-typesetting-cases.md) を参照。

## この一覧の読み方

- **E**：そのエンジン・仕様で定められる配置や既定動作。普遍的な出版規則とは限らない。
- **F**：フォントが提供する寸法・補正情報。具体値はフォントに依存する。
- **H**：学会誌・分野・出版物の表記方針。複数の採用可能な慣習がある。
- **J**：日本語組版の要件。元資料の文字クラスと適用範囲で読む。
- **D**：草案、または実装文書にある改行機能。実装環境ごとの確認が必要。

R01–R39 は収集した既存の規則・選択肢を示す。SUUSHIKI 固有の設計提案は [decisions.md](decisions.md) に分けた。「確認例」は未実行で、合格結果を示さない。

### TeX の自動間隔表

S01 の `math_spacing` を表形式に整理したもの。行が左の要素、列が右の要素。

| 左＼右 | Ord | Op | Bin | Rel | Open | Close | Punct | Inner |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Ord | 0 | t | m′ | k′ | 0 | 0 | 0 | t′ |
| Op | t | t | × | k′ | 0 | 0 | 0 | t′ |
| Bin | m′ | m′ | × | × | m′ | × | × | m′ |
| Rel | k′ | k′ | × | 0 | k′ | 0 | 0 | k′ |
| Open | 0 | 0 | × | 0 | 0 | 0 | 0 | 0 |
| Close | 0 | t | m′ | k′ | 0 | 0 | 0 | t′ |
| Punct | t′ | t′ | × | t′ | t′ | t′ | t′ | t′ |
| Inner | t′ | t | m′ | k′ | t′ | 0 | t′ | t′ |

`t`=thin、`m`=medium、`k`=thick、`′`=script / scriptscript では省く。`×` は Bin の再分類後には現れない組合せ。これは自動挿入の表であり、カーニング・明示的な空き・文字自体の幅を含む最終距離の表ではない。

S02 の自然幅を em で換算すると 1/6、2/9、5/18。mu はその数式スタイルの数学用 quad を基準とする単位で、本文の日本語全角幅と自動的に等しいわけではない。

S02 の伸縮指定は次のとおり。`plus` は伸び、`minus` は縮みの指定。

| 種類 | 自然幅 | 伸び | 縮み |
| --- | --- | --- | --- |
| thin | 3mu | 0 | 0 |
| medium | 4mu | 2mu | 4mu |
| thick | 5mu | 5mu | 0 |

## 適用上の注意

R32–R35 は JLREQ の対象文字列についての要件。数式ボックス全体をどの文字クラスに接続するかは、この一覧だけでは決定しない。

R36・R39 は著者向けの指針であり、レンダラーが入力式を無断でスラッシュ型や別の式へ書き換える根拠にはしない。表記変更・式の別行化・縮小・横スクロールは個別の方針として扱う。
